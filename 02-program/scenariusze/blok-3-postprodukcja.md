# Blok 3. Postprodukcja i formaty (2 h)

**Cel:** uczestnik zamienia surowe generacje w gotowe assety reklamowe we wszystkich formatach kampanii.
**Produkt:** komplet 1:1, 4:5, 9:16 i baner 16:9 z copy i logo.
**Efekty uczenia:** U3.

| Czas | Temat | Metoda | Wynik |
| --- | --- | --- | --- |
| 0:00–0:25 | Artefakty AI: „plastikowa” skóra, nienaturalna symetria, odbicia, tekst, dłonie | galeria błędów | oko do jakości |
| 0:25–1:00 | Retusz: Generative Fill, korekta koloru do palety marki, ziarno, wyostrzenie; upscaling | pokaz + ćwiczenie | 2 kreacje po retuszu |
| 1:00–1:10 | Przerwa | | |
| 1:10–1:40 | Adaptacja formatów: outpainting zamiast kadrowania, strefy bezpieczne UI, miejsce na logo i CTA | ćwiczenie | 4 formaty jednej kreacji |
| 1:40–2:00 | Layout w Canva/Photoshop: font marki, logo, CTA; eksport i nazewnictwo | ćwiczenie + omówienie | pakiet assetów |

**Specyfikacja eksportu:**

| Format | Rozmiar px | Zastosowanie |
| --- | --- | --- |
| 1:1 | 1080×1080 | post feed |
| 4:5 | 1080×1350 | post feed |
| 9:16 | 1080×1920 | Stories, Reels, TikTok |
| 16:9 | 1920×1080 | YouTube, baner |

**Nazewnictwo plików:** `NORDA_zimowy-baltyk_4x5_v03.jpg` (marka, kampania, format, wersja).
