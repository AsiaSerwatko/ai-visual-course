# Biblioteka promptów – kurs Grafika i wideo AI

Prompty po angielsku, bo modele obrazu i wideo nadal najlepiej rozumieją angielski. Komentarze po polsku. Parametry `--ar` dotyczą Midjourney; w innych narzędziach proporcje ustawia się w interfejsie.

Zasada pracy: **zmieniaj jeden element naraz** i zapisuj, co zmieniłeś. Wtedy wiesz, co działa.

---

## Blok 1. Fundamenty

### Szablon opisu kadru

```
[obiekt], [miejsce], [światło], [kadr: plan, kąt, obiektyw], [styl], [paleta] --ar [proporcje]
```

### P1.1 Moodboard bazowy NORDA

```
minimalist scandinavian coffee brand moodboard, navy blue and sand beige palette, winter baltic sea coast at dawn, soft natural light, film grain, editorial photography, calm and warm --ar 4:5
```

### P1.2 Warianty do moodboardu (zmieniaj po jednym)

Miejsce:

```
frosted sand dunes with dry grass, baltic coast, winter morning
```
```
wooden pier covered in light snow, calm grey sea, early morning
```
```
cozy minimalist coffee shop interior, light wood, large window with winter sea view
```

Światło:

```
soft overcast light
```
```
low golden hour sun, long shadows
```
```
blue hour, warm interior lights glowing
```

Detal / faktura:

```
close-up of hands in wool gloves holding a warm cup, steam rising
```
```
macro texture of frost on wood, shallow depth of field
```

### P1.3 Słownik pojęć kadru (PL → prompt)

| Pojęcie | W prompcie |
| --- | --- |
| Plan ogólny | wide shot, establishing shot |
| Plan średni | medium shot |
| Zbliżenie | close-up |
| Detal | extreme close-up, macro |
| Żabia perspektywa | low angle shot |
| Z góry | top-down view, flat lay |
| Na wysokości oczu | eye-level shot |
| Szeroki kąt | 24mm lens, wide angle |
| Standard | 50mm lens |
| Portretowy | 85mm lens |
| Płytka głębia ostrości | shallow depth of field, bokeh |
| Światło miękkie | soft diffused light, overcast |
| Złota godzina | golden hour |
| Światło kontrowe | backlit, rim light |
| Przestrzeń na tekst | negative space on the left |
| Ziarno filmowe | film grain, 35mm film |

### P1.4 Antystyl – czego unikać

W Midjourney: parametr `--no`. W innych narzędziach: pole „negative prompt” lub opis wprost („no text, no logos”).

```
--no oversaturated colors, plastic skin, stock photo smile, text, logo
```
